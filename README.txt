Election Party · מסיבת בחירות בג'ונגל
=====================================

מה יש בתיקייה
--------------
index.html               - האתר כולו, קובץ אחד. לחיצה כפולה פותחת אותו בדפדפן.
registrations-sheet.gs   - קוד שמחבר את טופס ההרשמה לגיליון Google בדרייב.

הגדרות באתר (בתוך index.html, בחלק <script>, בשורות הראשונות)
--------------------------------------------------------------------
PAY_URL       - קישור PayBox (כבר מוגדר)
WHATSAPP_URL  - קישור לקבוצת הוואטסאפ (כבר מוגדר)
SHEET_URL     - הקישור שמקבלים אחרי התקנת הקוד בגיליון (ריק כרגע)
TIER2_OPEN    - לשנות ל-true כשכרטיסי הנמר נגמרים, ואז האתר עובר לצב ב-140

העלאה ל-Vercel
--------------
האתר הוא קובץ סטטי אחד, אין צורך ב-build.

דרך 1, מהטרמינל (הכי מהיר):
  cd %USERPROFILE%\Documents\gungle
  npx vercel          (בפעם הראשונה: מתחברים ועונים על השאלות, Framework: Other)
  npx vercel --prod   (מפרסם לכתובת הקבועה)
אחרי כל שינוי בקובץ מריצים שוב: npx vercel --prod

דרך 2, דרך GitHub:
  מעלים את התיקייה ל-repo, ב-vercel.com/new עושים Import ל-repo,
  Framework Preset: Other, ולוחצים Deploy. כל push מעדכן את האתר.

חיבור לגיליון בדרייב
--------------------
ההוראות המלאות נמצאות בראש הקובץ registrations-sheet.gs.
בקצרה: גיליון חדש בדרייב, Extensions > Apps Script, מדביקים את הקוד,
Deploy כ-Web app עם גישה ל-Anyone, ומעתיקים את הקישור ל-SHEET_URL.

שימו לב: הגיליון מראה מי נרשם, לא מי שילם. את התשלומים מצליבים מול PayBox.
